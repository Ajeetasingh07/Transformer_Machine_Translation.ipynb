# Transformer-Based Machine Translation Pipeline

## 📌 Project Overview

This project develops a **Transformer-based machine translation pipeline** for translating text from **English to Hindi**.

The project uses a pretrained Transformer model and fine-tunes it on an English-Hindi parallel dataset. The main objective is to build a practical NLP system capable of producing accurate translations and handling domain-specific terminology.

## 🎯 Objectives

* Build an English-to-Hindi machine translation system.
* Understand and implement Transformer-based NLP techniques.
* Fine-tune a pretrained sequence-to-sequence translation model.
* Evaluate translation performance using standard machine translation metrics.
* Create a simple translation demonstration.

## 🧠 Model

The project uses the pretrained:

**Helsinki-NLP/opus-mt-en-hi**

This model is designed for English-to-Hindi machine translation and is further fine-tuned using parallel English-Hindi sentence data.

## 📊 Dataset

The project uses the **IIT Bombay English-Hindi Parallel Corpus**.

The dataset contains paired English and Hindi sentences that can be used to train and evaluate machine translation models.

For the initial training experiment, a smaller subset of the dataset is used to make training practical in Google Colab.

## 🚀 Implementation Steps

1. Set up the Google Colab environment.
2. Load the English-Hindi dataset.
3. Select training, validation, and test samples.
4. Load the pretrained tokenizer.
5. Tokenize English and Hindi sentences.
6. Load the pretrained Transformer model.
7. Fine-tune the model on the training dataset.
8. Evaluate the model.
9. Test the model on new English sentences.
10. Calculate translation performance using BLEU score.
